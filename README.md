# Happy One Year to us Heart Landing

Dark premium landing page recreated from reference using:

- Vite + React + TypeScript
- TailwindCSS
- GSAP
- Mathematical heart grid + Unsplash image sourcing

## Run

```bash
npm install
npm run dev
```

## Image source

The current build uses a curated list of unique Unsplash image IDs, so each card renders a different image.  
If any URL fails, the tile auto-falls back to a fixed Unsplash image.
